Backend API · Vercel + Neon

🔐 WarrantyVault Backend

API is running on Vercel with Neon Postgres and Neon S3 storage.

Endpoints (POST only)

POST/api/process-document
File → Gemini extraction → Neon Postgres + Neon S3
Body: { "document_id": "..." }
Header: Authorization: Bearer <token>
POST/api/delete-document
Delete storage object + database row
Body: { "document_id": "..." }
POST/api/delete-account
Full account erasure: files, rows, auth user
POST/api/draft-warranty-email
Draft warranty claim email (no auto-send)
Body: { "warranty_id": "...", "issue_text": "..." }
